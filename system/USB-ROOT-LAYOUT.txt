Normal startup: Dr.Swintus\ASK-AGENT.cmd.lnk
The shortcut targets Dr.Swintus\system\ASK-AGENT.cmd and uses the system folder as its working directory.
No fallback root CMD launcher is required.
No other Dr.Swintus runtime folders are created at the USB root.
