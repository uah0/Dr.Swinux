# Dr.Swinux branding

`dr-swinux.png` and `dr-swinux-icon.png` are derived only by cropping/scaling the user-approved reference PNG supplied for the project. The mascot must not be redrawn or approximated.

`dr-swinux.png` is the main raster asset. `dr-swinux-icon.png` is the compact asset for small UI surfaces. `Create-Shortcut.ps1` derives the Windows `dr-swinux.ico` from the compact PNG at build/start time.

No SVG redraw is a branding master. These two PNG files are the only committed branding images used by the release.
